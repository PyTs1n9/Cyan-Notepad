## 任务 1｜固定展开箭头（已定位根因）

根因：箭头 `absolute top-1/2 -translate-y-1/2` 的定位父级是**清单行 wrapper**，展开后 wrapper 高度包含整块展开区，`50%` 变成整块的一半，箭头下沉到展开区中间。

**改法**：把箭头锚定在清单行自身的 32px 带内（`top-0 h-8` + `items-center`，或 `top-4 -translate-y-1/2`），不得依赖 wrapper 高度。

**验收**：展开/收起任意清单，箭头始终与清单行文字基线对齐，不随展开区高度移动。

## 任务 2｜清单行改为右键菜单

1. 删除双击进入重命名的入口（`onDoubleClick={() => startRename(list)}`）。
2. 右键清单行 → `TreeContextMenu`，菜单项：
   - 重命名（进入行内编辑并聚焦，`Enter` 提交、`Esc` 取消）
   - 置顶 / 取消置顶
   - 展开任务 / 收起任务（该清单无任务时 `disabled`）
   - 在此清单新建任务（切到该清单并聚焦主区条带的输入框）
   - 分隔线后：删除（`danger`，走现有 `deleteConfirmList` 确认弹窗，不直接删）
3. 删除 hover 的三个悬浮按钮及其容器。
4. 右键不得同时切换选中清单。

**验收**：双击不再编辑；右键出现完整菜单；菜单项逐个可用；删除仍弹确认。

## 任务 3｜新建清单移到左栏头部右侧

1. `TodoStrip` 删除新建清单按钮与其浮层，并清掉不再使用的 state / 图标 import（留死代码算不合格）。
2. `TodoSidebar` 的 `h-9` 头部右侧，加入新建清单按钮（放在 `进行中/已完成` 计数旁）。点击就地展开命名输入（浮层或内联均可），宽度 ≤ 200px。
3. 创建成功后：新清单成为当前清单，输入框自动聚焦。
4. `Esc` 关闭、外点关闭、`Enter` 提交。

**验收**：左栏 240px 与 400px 两种宽度下浮层完整可见、可输入、不被 `.shell-box` 的 `overflow: hidden` 裁切。

## 任务 4｜展开区任务行右键（本轮范围）

右键展开区的**任务行**（非子待办行）→ `TreeContextMenu`：
- 打开 / 编辑描述（等价于点行内的描述图标）
- 添加子待办
- 置顶 / 取消置顶
- 分隔线后：删除（走现有确认弹窗）

子待办行本轮不加右键。

**验收**：右键任务行菜单可用，且不会触发该行的勾选切换。

## 任务 5｜保护已完成的描述交互（不要回退）

- 描述入口只在 hover 时出现（无描述时行内不留任何占位），已有描述时图标常显为 accent 色。
- 描述卡片：有内容才渲染；点卡片进入编辑；`Ctrl+Enter` 或「保存」提交；`Esc` 取消；点别处失焦提交。
- 左栏展开区对「有描述」的标记必须是**纯元素**（当前是一个 1px 圆点），不得再引入图标组件。

## 遗留风险（必须处理）

上一版在左栏展开含描述任务的清单时出现过一次崩溃，用户无法提供堆栈。已做的规避：把左栏唯一依赖 `description` 的节点从 lucide 图标换成纯 `span` 圆点，并对 `typeof todo.description === "string"` 做类型判定。
