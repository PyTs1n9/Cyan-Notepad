# 青记（Qing Notepad）功能手册

青记是一款 Windows 桌面记事应用：Markdown 笔记、待办清单、自由画布、便签与磁贴、主题定制，本地功能免登录，另有可多人协作的在线工作台。AI 助手「小青」依据本手册回答使用问题。

## 界面布局

窗口从左到右分四个区：

- **活动栏**：最左边的图标栏，切换「记事」「待办」「画布」「在线工作台」，底部是「设置」。
- **侧边栏**：随视图显示笔记树、清单列表、画布列表或工作台成员。可拖动分隔条调宽，也可折叠。
- **内容区**：顶部是标签页栏，可同时打开多篇笔记。
- **标题栏**：窗口控制按钮、常用操作和退出入口。

## 记事：Markdown 编辑

### 三种视图

工具栏随时切换：

- **源码**：直接编辑 Markdown 文本。
- **预览**：只看排版效果。
- **分屏**：左边编辑、右边预览，滚动同步。

### 保存

- 内容**自动保存**，间隔在设置里调（10 秒 / 30 秒 / 1 分钟，也可关闭）。
- 按 `Ctrl+S` 立即保存；切换或关闭笔记时也会自动存好，不会丢。

### 图片

把图片**粘贴或拖进**编辑器即可，图片随笔记自动保存并插入引用。预览支持本地图片和网络图片。

### 导入与导出

- **导入**：`.md`、`.markdown`、`.txt` 文件，导入后是一篇新笔记。
- **导出**：点「导出文件」，可存为 Markdown、纯文本、Word（.docx）或 PDF。

### 整理笔记

- **文件夹**：笔记树里可新建、重命名、删除文件夹；右键笔记选「移到文件夹」换位置。
- **标签页**：单击笔记开预览标签（标题是斜体），双击转正式标签，标签可固定。
- **搜索**：侧边栏搜索框按标题和正文过滤笔记，可叠加文件夹、标签筛选。
- **标签筛选**：侧边栏下方列出笔记的标签，点一下只看该标签的笔记。
- **回收站**：删掉的笔记进回收站，可恢复或彻底删除；超过保存时间自动清理，时长在设置里调。

## 待办清单

- 可建**多个清单**，各清单任务互不相通。清单可重命名、置顶、拖动排序。
- 任务可设**低 / 中 / 高**优先级和**截止日期**，支持勾选完成、行内编辑、拖拽排序，按状态或优先级筛选。
- 完成的任务自动沉底。删清单会连任务一起删掉，且不能撤销。

## 自由画布

- 画布上可放**图片和多行文字**，支持框选、拖动、缩放、画笔涂鸦。
- 可导出 **PNG、JPEG、SVG** 图片，也可点「创建画布磁贴」把画布钉成桌面小窗。
- 画布是本地功能，**不参与**在线工作台协作。

## 便签与磁贴

- **便签**：置顶的**可编辑**小窗，放桌面随手记。打开一篇笔记，点工具栏的图钉按钮（界面上叫「钉住磁贴」）即可；关掉小窗不影响笔记。
- **磁贴**：**只读**的笔记小窗，把资料钉在屏幕一角看。画布也有磁贴，在画布工具栏点「创建画布磁贴」。

## 在线工作台与实时协作

在线工作台需要联网并登录；未配置在线服务时，本地功能照常使用。

- **账号**：邮箱注册、登录、退出、改密码，昵称与头像管理。
- **工作台**：自己创建，或用**邀请码**加入别人的工作台。
- **协作**：文档多人实时编辑，能看到在线成员，框选内容可高亮给别人看；成员变动、被移出会实时提醒。
- 断网时的修改先存本机，恢复网络和登录后自动同步。

## 个性化设置

活动栏底部点「设置」：

- **主题**：想换主题在这里——深色、蓝调、忧郁黄、清新绿四套预设，可自定义配色和背景图（JPG / PNG / WebP），最多存 5 套自定义预设。
- **语言**：中文 / English 即时切换。
- **全局快捷键**：默认 `Ctrl+Space` 显示 / 隐藏窗口，可改成别的按键。
- **AI 设置**：填 DeepSeek API Key，用于小青问答和笔记润色。Key 加密存在本机。
- **检查更新**：关于窗口里检查新版本并跳转下载。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+S` | 保存当前笔记 |
| `Ctrl+Space` | 显示 / 隐藏主窗口（全局生效） |

要改快捷键：到「设置 → 快捷键设置」修改按键，或点「恢复默认」。

点关闭按钮只是**最小化到托盘**；要真正退出，用托盘菜单的 `Quit` 或标题栏的「退出软件」。

## 数据存储与备份

- 本地内容都存在安装目录下的 `data` 文件夹；如果安装目录不可写，会存到 `C:\Users\<用户名>\AppData\Roaming\com.qing-notepad.app\data`。
- 备份就是复制整个 `data` 文件夹：笔记、待办、画布、图片、设置都在里面。
- 在线工作台的内容存在云端，换电脑后登录同一账号即可找回。

## AI 助手「小青」与笔记润色

- **AI 助手「小青」**：右侧栏对话，回答软件使用问题。知识来自本手册与常见问答，检索**全在本机**，不联网、不上传。没配 API Key 时直接给出检索到的原文；配好 Key 后由 DeepSeek 组织成完整回答。
- **笔记修改权限**：输入栏模型选择右侧的开关，两档——「仅助手」（默认，只回答、不改笔记）与「完全开放」（AI 直接修改笔记正文与标题，立即生效）。每次修改前自动存快照，在那条回答下点「撤销此次修改」即可回退；开启前会确认一次。小青永远只读，开关只对 API 模型生效。
- **笔记润色**：选中笔记里的一段文字，让 AI 润色或改写。修改先给你看**前后对比**，点「应用」才写入；写入前自动存快照，可一键撤销。
- **联网搜索**：在「设置 → AI 设置」里打开「联网搜索」即可，不用另填 Key——用的就是同一把 DeepSeek Key，按成功请求次数计费。开启后用 DeepSeek 提问会先搜网页，回答里标注来源；搜索没成功时回答照常给出，只是少了网页内容。小青不联网。
- 发给 DeepSeek 的只有**选中的段落**或**相关的笔记片段**（每段很短）；开启「完全开放」后，AI 改某篇笔记前会把**这一篇**的内容发给 DeepSeek，其余笔记仍只发片段。开启联网搜索后，你的提问还会发给 DeepSeek 的搜索服务。
