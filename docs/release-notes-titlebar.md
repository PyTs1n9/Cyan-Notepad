# 顶栏改版说明（面向用户）

本次改版只动「入口在哪」，**没有删除任何功能**。旧位置的每一项都能在新位置找到，
下表可直接作为发布说明的迁移对照。

## 一句话

标题栏原来的「工具」「传送门」「帮助」三个下拉菜单，合并为一个 **帮助菜单**；
视图切换交给左侧图标栏，文档操作回到各自的工具栏。标题栏更短，入口更少，但每个动作只剩一个明确的家。

## 入口迁移对照

## 行为变化（值得知道的三条）

1. **退出会先确认，并先落盘。** 以前点「退出软件」立刻退出；现在会弹一次确认，且在确认前把
   当前笔记的未保存修改写进本地文件。窗口右上角的 `×` 仍然是「最小化到托盘」，不是退出。
2. **未登录也能退出。** 以前只有登录后点头像才有菜单；现在头像对所有人可点，里面同时有
   「登录」和「退出软件」。
3. **工具栏按钮不会再被裁掉。** 编辑卡片变窄时，工具栏会换行而不是把最右边的按钮切掉。

## 已知取舍

- **导出有两个入口**（工具栏按钮 + 标签页右键）。这违反了本次改版「一个动作一个入口」的原则，
  但有明确理由：工具栏负责「看得见」，右键负责 Windows 用户「文件操作先右键」的直觉。
  两处调用的是同一个函数，不会出现两种导出行为。
- 画布操作说明从「一眼可见」变成「帮助 → 画布使用说明」，多了一次点击，换来标题栏不再有
  一个会随视图变形的菜单。
